# BoardState v3：磁贴、花名册、值日与点名

> v2 的字段全部保留（课表、作业、通知、主题、调休…），改的只有两处：
> **`blocks` 变成 `layout` 的 12×8 磁贴网格**，**新增 `roster` / `duty` / `today.call`**。
> 契约文件：`board-web/schema/board-state.v3.schema.json`。字段级约束以 schema 为准，这里讲"为什么"和"渲染端怎么算"。

## 1. 为什么换成磁贴

v2 把版面写死成三栏（main / side / strip），老师看到的永远是同一个样子：作业占左半边、待办在右上、课表在右下、底部一条通栏。可教室之间差别很大——有的班要放值日表，有的班想先看课表，有的班一块屏要塞两个班的对比。**布局是老师的决定，不该由代码写死。**

v3 把整块屏切成 **12 列 × 8 行**，每个组件是一块磁贴，位置和大小都由老师拖出来：

```json
"layout": {
  "cols": 12,
  "rows": 8,
  "tiles": [
    { "id": "hw", "block": "homework", "x": 1, "y": 1, "w": 7, "h": 4 },
    { "id": "td", "block": "todo",     "x": 8, "y": 1, "w": 5, "h": 2 },
    { "id": "tt", "block": "timetable","x": 8, "y": 3, "w": 5, "h": 3 },
    { "id": "du", "block": "duty",     "x": 1, "y": 5, "w": 4, "h": 2 },
    { "id": "nt", "block": "notice",   "x": 5, "y": 5, "w": 4, "h": 2 },
    { "id": "rc", "block": "rollcall", "x": 9, "y": 6, "w": 4, "h": 2 }
  ]
}
```

- `x` / `y` 从 **1** 开始，`w` / `h` 是占几格；`x+w-1 ≤ 12`、`y+h-1 ≤ 8`（校验器只查范围，不查越界，**越界的磁贴渲染端直接裁掉不画**）。
- 为什么是网格不是自由像素：12×8 吸附在任何分辨率下都不会叠在一起，手机上也拖得动；自由坐标在 1080p 上摆好的版，到 4K 或 16:10 的教室就会散。
- 磁贴可以重叠（数组顺序靠后的压在上面），但老师端不允许放下重叠的磁贴——重叠是数据坏了，不是功能。

## 2. 渲染端怎么摆

- 一个 CSS Grid（`grid-template-columns: repeat(12, 1fr)`、`repeat(8, 1fr)`），每块磁贴 `grid-area: y / x / span h / span w`，所以按百分比自动缩放。
- 头部（问候 / 日期 / 时钟 / badge）仍是固定的，不占网格。
- 每块磁贴：标题栏 + 内容区。内容装不下时按三级处理：先降字号（`.is-tight` / `.is-tighter`），再分页（`core/pager.js`，9s 一页），`tile.flip === "off"` 的只显示第一页。
- 组件自己决定"没数据就不画"：`render()` 返回 `null` 时整块磁贴消失（比如今天没课，课表磁贴就不占地方）。

## 3. 十一种磁贴

| block | 内容 | 数据来源 |
| --- | --- | --- |
| `homework` | 今日作业（按科目分组，每条最多两行） | `today.homework` + `subjects` |
| `todo` | 今日待办 | `today.todo` |
| `timetable` | 今日课表（含调休/放假 badge） | `schedule` + `overrides` + `periods` |
| `notice` | 班级通知 | `today.notice` |
| `duty` | 今日/本周值日生 | `duty` 规则 + `roster` |
| `rollcall` | 点名：最近抽到的学生 | `today.call` |
| `countdown` | 倒计时 | `countdown` |
| `quote` | 寄语 | `today.quote` |

`title` 可覆盖默认标题（最多 8 字），不填就用组件的默认名。

八块磁贴**不是同一个样子**：每块在渲染端有一种 `skin`（list / timeline / checklist / roster / announce / spotlight / quote），说的是"这块怎么说话"——作业是一条条要抄的清单、课表是时间轴、倒计时是整块一个大数字、寄语直接不要卡片底。`spotlight` 与 `quote` 不显示标题栏。细则见 `board-web/README.md` 的「磁贴的几种说法」。老师端的「布局」画布画的是同一套骨架：拖之前就能分清哪块是清单、哪块是时间轴。

## 4. 花名册、值日与点名

### roster

```json
"roster": {
  "students": [{ "id": "s1a2b3", "name": "张梓萱", "no": "01" }],
  "updatedAt": "2026-11-05T12:00:00+08:00"
}
```

- `id` 是 4–16 位小写字母数字，老师端导入时生成，**改名不换 id**（值日轮换靠它稳定）。
- 最多 80 人；`no`（学号）可选，只用来排序和显示。
- 导入方式：粘贴文本（一行一个名字，可从 Excel 直接复制一列）或上传 CSV（第一列姓名、第二列学号，有表头自动跳过）。

### duty

```json
"duty": { "mode": "weekly", "size": 4, "anchor": "2026-09-01" }
```

- `mode: "weekly"` 每组值一周，`"daily"` 每天一组，`"off"` 不自动排。
- 分组就是**按花名册顺序切成每 `size` 人一组**，周次/天数从 `anchor` 算，`(第几组) = floor(经过的周数) % 组数`。
- `anchor` 缺省时用当年 9 月 1 日（开学）。渲染端只读规则和名单，自己算今天该谁——服务端不存"今天是谁"。
- 手写的 `today.duty.text` 一旦存在就盖过自动排班（老师临时换人不用改规则）。

### today.call

```json
"today": { "call": { "name": "李思远", "at": "2026-11-05T14:32:00+08:00" } }
```

老师手机上点「抽一个」→ 老师端自己从花名册随机挑一个（尽量避开最近点过的），写进 `today.call` → 保存发布 → 大屏那块点名磁贴显示名字。超过 24 小时不显示（早读点的，下午不该还挂着）。

**为什么不在服务端抽**：服务端只存老师写下去的东西，抽人是老师端的一次编辑——这样"撤回/重抽/手改"都只是改 `today.call` 这一个字段，不需要新接口。

## 5. 老数据怎么办

启动时按 `version` 逐个升：`1 → 2 → 3`。v2 → v3 的映射：

- `blocks[]`（type + column + order）→ `layout.tiles[]`，用一张固定的"老样子"模板（作业 7×4 左上、待办 5×2 右上、课表 5×3 右下、值日 4×2、通知 3×2 底部——课表占到第 5 行，通知缩到 3 格才不压住它），保证升级后**屏幕上的东西一点不少**，只是从此可以拖。
- 没有 `roster` / `duty` 的，留空：值日磁贴继续用 `today.duty.text`（老班级照旧），花名册磁贴不画。
- 倒计时和寄语在 v2 里不在 `blocks`（一个在头部、一个在页脚），但版面上一直显示，所以只要 `countdown.date` / `quote.text` 有数据就各补一块（倒计时 1,7 3×2、寄语 4,7 4×2）——不补的话老班升级后这两样会凭空消失（生产实测只剩 4 块）。
- 老班级**不会**自动多出点名磁贴（v2 里根本没有这个功能）：需要点名就先去班级页导花名册，再到「布局」页把点名磁贴拖上去。
- 升级算一次内容变更（`revision + 1`），在线大屏收到推送重拉。

## 6. 老师端怎么改

- **布局**页签：12×8 画布，拖磁贴改位置、拉右下角改大小、右上角 × 删、底部「+ 添加磁贴」。放下时吸附到格子，越界夹回，重叠回弹。画布上方一排「预置布局」：均衡 / 作业优先 / 一天的安排 / 数字墙 / 清爽，一键换整套摆放（只动位置和大小，内容不动，已有磁贴时先确认）。
- **班级**页：花名册卡（粘贴/上传/列表/清空，另有「用示例名单」放 12 个例子进去改）+ 值日规则（按周/按天/不排 + 每组几人）。
- **今日**页：花名册不为空时出现「抽一个」，抽到谁就写到 `today.call`，同时给一个「取消点名」。

## 7. 新班级不是空的

建班成功的那一刻，服务端就写好了第一版快照（`revision: 1`）：8 块磁贴（用「均衡」那套）、12 个示例学生、一套周一到周五的课表、语文/数学/英语三条示例作业、两条待办、一条家长会通知和一句寄语，倒计时算到下一个期末。

老师要做的是**改**，不是从空屏开始填。第一遍发布从 `revision 2` 起。

数据都在 `publish-api/presets.js`（`LAYOUT_PRESETS` / `SAMPLE_STUDENTS` / `sampleState`），老师端通过 `GET /api/v1/board/presets` 拿前两份，用来画「预置布局」和「用示例名单」。
